Projeto freelancer de portfólio online para **Daniel**, designer e ilustrador. Um site moderno, responsivo e curado visualmente para apresentar trabalhos de identidade visual, ilustração, design UX e audiovisual.

## ✦ Stack

| Camada | Tecnologia |
|--------|-----------|
| Framework | React 19 |
| Linguagem | TypeScript 6 |
| Build | Vite 8 |
| Estilização | Tailwind CSS 4 |
| Componentes | shadcn/ui (base-ui) |
| Animações | CSS custom (scroll reveal, parallax) |
| Deploy | Vercel |
| Domínio | domportifolio.com.br |

## ✦ Seções

1. **Home** — Hero editorial com chamada principal
2. **Sobre** — Trajetória, skills e abordagem criativa
3. **Formação** — Educação acadêmica e cursos
4. **Ilustração** — Galeria de trabalhos
5. **Design | UX** — Projetos de design e experiência
6. **Identidade Visual** — Branding: Camookie, Moves Dance
7. **Audiovisual** — Motion design e vídeo
8. **Contato** — Redes, Instagram e formulário com EmailJS

## ✦ Comandos

```bash
npm run dev       # Desenvolvimento
npm run build     # Build produção
npm run preview   # Preview do build
npm run lint      # ESLint
```

## ✦ Ambiente

Crie um arquivo `.env` na raiz com as credenciais do EmailJS:

```
VITE_EMAILJS_SERVICE_ID=seu_service_id
VITE_EMAILJS_TEMPLATE_ID=seu_template_id
VITE_EMAILJS_PUBLIC_KEY=sua_public_key
```

## ✦ Cérebro Criativo

O vault Obsidian em `Cerebro do portfólio/` documenta o processo criativo com notas interligadas sobre projetos, habilidades e experiências.
